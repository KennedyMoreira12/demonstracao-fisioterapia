# Demonstracao - LJ SmartClinic versao Fisioterapia

Material de demonstracao preparado para a Clinica de Fisioterapia de Daiane
Teixeira: o que ja esta disponivel, as telas da demonstracao, as
funcionalidades planejadas e os pontos para confirmar com a clinica.

- `index.html` - apresentacao navegavel (abra no navegador)
- `demonstracao-fisioterapia.pdf` - a mesma apresentacao em PDF

Todos os dados das telas sao ficticios, criados apenas para demonstrar a
rotina. Nenhum paciente real foi usado.
